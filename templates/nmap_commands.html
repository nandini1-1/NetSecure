NMAP REFERENCE

Nmap Scan Commands

Learn about the Nmap scanning techniques implemented in NetSecure and understand what each scan is designed to discover.

01

TCP Connect Scan

nmap -sT <target>

Performs a full TCP connection using the operating system's networking stack. It is useful when raw packet privileges are not available.

Option: -sT Detects: Open and closed TCP ports
02

SYN (Stealth) Scan

nmap -sS <target>

Sends TCP SYN packets to identify open ports without completing the full TCP handshake. It is one of Nmap's commonly used TCP scanning techniques.

Option: -sS Detects: Open TCP ports
03

UDP Scan

nmap -sU <target>

Scans UDP ports to identify services that communicate using UDP, such as DNS, SNMP, and DHCP.

Option: -sU Detects: Open and open|filtered UDP ports
04

Ping Scan

nmap -sn <target>

Performs host discovery without performing a traditional port scan. It determines whether the target host is responding.

Option: -sn Detects: Live or reachable hosts
05

Version Detection

nmap -sV <target>

Probes discovered services to determine the application name and version running on open ports.

Option: -sV Detects: Services and versions
06

OS Detection

nmap -O <target>

Analyzes network responses and TCP/IP characteristics to attempt to identify the operating system of the target.

Option: -O Detects: Operating system and OS characteristics
07

Aggressive Scan

nmap -A <target>

Enables several advanced detection features together, including operating system detection, version detection, default NSE scripts, and traceroute.

Option: -A Detects: OS, services, versions, scripts and routes
08

Service Discovery

nmap -sV -sC <target>

Combines service and version detection with Nmap's default NSE scripts to gather additional information about detected services.

Options: -sV -sC Detects: Services, versions and script information
09

Fast Scan

nmap -F <target>

Performs a faster scan by checking a smaller list of commonly used ports instead of Nmap's larger default port set.

Option: -F Detects: Commonly used ports
10

Full TCP Port Scan

nmap -p- <target>

Scans the complete TCP port range from port 1 through port 65,535. This provides broader TCP port coverage than a default scan.

Option: -p- Detects: TCP ports across the full port range

⚠️ Responsible Scanning

Nmap should only be used against systems, networks, and applications that you own or have explicit permission to assess.
